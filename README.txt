AI-Powered Omni Robot

A four-wheel omni-directional robot controlled by AI hand gestures.

Run the Camera

1. Open the project

cd ~/robot_parul_project

2. Activate the virtual environment

source .venv/bin/activate

3. Start the laptop camera

python ai/camera.py

Press q to close the camera.

4. Deactivate the virtual environment

deactivate
